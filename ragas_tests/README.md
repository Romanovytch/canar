# Ragas demo

Simple evaluation demo using [Ragas](https://docs.ragas.io/en/stable/tutorials/rag/) to measure RAG quality.

## What it does

The script `eval.py` takes 3 hardcoded Q&A samples and scores them with 3 metrics:

| Metric | What it checks |
|---|---|
| `faithfulness` | Is the answer grounded in the retrieved context? Catches hallucinations. |
| `answer_relevancy` | Does the answer actually address the question? |
| `factual_correctness` | Does the answer match a reference (ground truth)? |

Each metric uses the LLM internally to "judge" the quality — ragas sends structured prompts and parses the responses into a 0–1 score.

## How it maps to our project

| Ragas field | In our stack |
|---|---|
| `user_input` | Query typed in canar |
| `retrieved_contexts` | Chunks returned by Qdrant (ingested by agora) |
| `response` | Answer generated by the LLM in canar |
| `reference` | Ground truth written by a domain expert |

## Setup

```bash
# already done — venv is at .venv/
cp .env.example .env   # already configured for Ollama
```

## Run

```bash
.venv/bin/python eval.py
```

Results are saved to `experiments/results.csv`.

## Notes

- Uses `qwen3.5:9b` via Ollama (local) as both the answer generator and the evaluator LLM.
- Embeddings: `nomic-embed-text:v1.5` via Ollama.
- `localhost` must be written as `127.0.0.1` in the `.env` — Python resolves `localhost` to IPv6 but Ollama listens on IPv4 only.
- Ragas version: 0.2.15 (patched to remove broken VertexAI import from `langchain-community 0.4`).
